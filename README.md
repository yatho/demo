# Feature Voting App

A modern internal feature voting portal for tracking and voting on feature requests.

## Installation

```bash
npm install
```

## Running the Application

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Running Tests

```bash
npm test
```

## Building for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Features

- View feature requests across multiple categories
- Vote for feature requests you'd like to see
- Filter requests by category (AI, Platform, Mobile, Security)
- Dashboard with voting statistics
- Modern, responsive UI
